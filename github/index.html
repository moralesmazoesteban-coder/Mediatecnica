Acerca de GitHub

¿Que es GitHub?

GitHub es una plataforma para guardar, compartir y trabajar con código. También permite colaborar con otras personas en proyectos de programación.

CARACTERISTICAS

Las principales características de GitHub son:
  1. 💻 Guardar código
  2. 👥 Trabajar en equipo
  3. 🕒 Controlar cambios y versiones
  4. 🌐 Compartir proyectos

¿COMO SE USA?

GitHub se usa para guardar y organizar proyectos de programación en Internet.
  1. Creas una cuenta en GitHub.
  2. Creas un repositorio, que es donde estará tu proyecto
  3. Subes tus archivos y código
  4. Guardas los cambios que hagas en el proyecto
  5. Puedes colaborar con otras personas y compartir tu proyecto

¿PARA QUÉ SE UTILIZA?

GitHub se utiliza para guardar, compartir y organizar código, además de trabajar en equipo y controlar los cambios de un proyecto.

¿QUE EMPRESAS Y/O ENTIDADES SON LAS QUE MAS UTILIZAN ESTE PROGRAMA?

GitHub es utilizado principalmente por empresas y organizaciones que desarrollan software. Algunos ejemplos son:
  • Microsoft
  • Google
  • Shopify
  • Ford
  • Amazon
  • Adobe
  • Spotify
También es muy utilizado por universidades, startups y desarrolladores independientes. GitHub indica que alrededor del 90 % de las empresas Fortune 100 utilizan su plataforma.
